# Venue Selection Prompt (Stage 2)

## Goal
Select a culturally grounded, realistic venue and conversational activity for a first date that connects directly with both candidates' documented interests.

## Rules
- Fictional but plausible venue in a city that fits both candidates.
- Activity tied to evidence (e.g., bookstore café for two bibliophiles, natural wine listening bar for music & culinary buffs).

## Output Schema
```json
{
  "name": "Bar Gemini",
  "city": "San Francisco, CA",
  "activity": "Low-intervention natural wine tasting and ambient vinyl listening",
  "rationale": "Directly bridges Elena's natural wine enthusiasm and Marcus's generative sound interests."
}
```
