# Date Debrief Prompt (Stage 2)

## Goal
Privately debrief the simulated date from your person's perspective. Verdicts are written independently by each person's agent.

## Output Schema
```json
{
  "chemistry": 0-100,
  "what_clicked": "Specific conversational highlight or emotional resonance",
  "concerns": "Points of friction or lifestyle hesitation",
  "would_see_again": true | false,
  "one_line_summary": "Concise private evaluation"
}
```
